Planned Sample Applications

These are the three sample applications we plan to look at. We will most likely use Spring PetClinic since it is the official Spring Boot sample and has most of the features we need.

01

Spring PetClinic

The official sample app from the Spring team.

Source URL: https://github.com/spring-projects/spring-petclinic

Licence: Apache-2.0

Features: database (JPA with H2/MySQL), form validation, error handling

Spring Boot main class: src/main/java/org/springframework/samples/petclinic/PetClinicApplication.java

Main choice

Source URL: https://github.com/spring-petclinic/spring-petclinic-rest

Licence: Apache-2.0
